# Project 1

This repository includes the files for Project 1 for CIVE 202. 

Per a Request for Proposal (RFP) from UNMC Water, Climate, and Health, this project will develop an analysis of air quality in Nebraska. The client has requested four analyses: (1) determination of the five Nebraska locations where the mean and median values of VOC, PM 2.5, and PM 10.0 are the highest, (2) analyses of when and where the maximums occurred and any potential reason why, (3) if humidity and temperature affect air quality, and (4) determination of any Air Quality Index (AQI) health risks based on the EPA’s AQI ratings at any of the Nebraska locations for PM 2.5 and PM 10.0.
